# 西瓜与小鸟：低换手策略协作内核

这是可移植的 Python 信号、持仓计划与开盘委托估算内核，供共同开发使用。默认保留已采用的动态低换手规则；晚买、晚卖候选仅作为独立研究函数。中文方法和结果经过重新整理，仓库不含市场数据、真实交易记录或私有环境快照。

## 直接运行

Python 3.10 及以上，仅用标准库。从本仓库根目录运行，无需安装依赖：

```sh
python -B -m examples.synthetic_demo
python -B -m unittest discover -s tests -v
```

演示在内存中生成虚构股票状态和价格，输出排名、持仓意图和含费数量估算。它不执行委托、不计算历史收益。测试覆盖数据缺口、历史资格、时点、冻结仓位、股数与费用、实验条件和因果性。

## 默认策略

在当时完整 A 股池中排除北交所、ST、停牌和无有效成交股票，要求上市满 365 自然日、未到已知退市日、收盘价及总市值为正。最近 20 个市场交易日必须有 20 条可核验记录，Turn20 只对其中有效成交日取换手率均值，单位为百分数；按 float32 分数、股票代码升序排列。

每日收盘形成排名，下一市场交易日开盘执行。新买只取 Top10；实仓排名在 Top15 内，或实际买入后尚未完成 30 个市场交易日，就保留原股数。满 30 日且落出 Top15 才形成退出意图，保留仓不重复买卖、不机械等权再平衡。最短持有期内已有 ST 不额外强卖，新 ST 不新买。

[默认配置](config/default.json)：初始 10 万元、Top10 / Top15、最少 30 交易日、佣金万二且每笔最低 5 元、单边滑点 10bp、前一市场交易日成交额 1% 容量。印花税和过户费明确标为 **2024—2026 研究参数**，历史或未来适配器须按日期传入费率。账户自然复利，不每日补款。

## 工程进展与研究结论

工程上已从月末轮换转为每日检查、最短持有期和观察区；保留重复持仓，修正停牌日平均分母，并在原研究中加入成本、资金冻结和公司行动核验。本内核把这些规则与数据、成交和账本适配器分开，显式拒绝不完整股票池和未知关键数据。没有证据把某一工程修正单独量化为收益增益；当前动态版也不是视频月度版的完全复现。

**测试过的等待规则未找到跨阶段、跨起点的稳定优势。** 近期固定原买入、只延后卖出的 20 万元账户对照中，原卖出累计 41.07%，走平晚卖 39.95%，涨速减弱晚卖 39.39%。这些数字来自已验收原研究环境，本轮没有用新内核重跑行情。完整分母、失败实验和限制见[研究结果](docs/research_results.md)。
